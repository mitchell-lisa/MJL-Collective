# mjlcollective.com

Static site for MJL Collective. The design puts the client work first: real
screenshots of the client sites, desktop and phone, laid out like a magazine
spread, on MJL's own palette (poured dark, plaster, cement, mortar, ink) with
the lockup set large in the footer. No accent color: the client sites bring the
color.

## Editing

Every page is generated by `tools/build.py` from one template, so the bar, the
footer and the head stay identical. Edit the copy in `tools/build.py`, then run

    python3 tools/build.py

and commit the regenerated `.html` files. Privacy and Terms bodies are stored
verbatim in `tools/content/` and dropped into the template unchanged (they are
needed for the Twilio SMS registration, so edit them only on purpose). `tools/`
is listed in `.vercelignore` and is not deployed.

Bump `V` in `tools/build.py` whenever `assets/site.css` or `assets/site.js`
changes, so phones don't keep a cached stylesheet.

## Type and color

- Instrument Sans (the wordmark's face) for headlines, nav, buttons and captions.
- Source Serif 4 for anything you read.
- Both are self-hosted in `assets/fonts/`.
- Palette, used on every page and nowhere else: poured `#2b2825`, ink `#1c1a17`,
  plaster `#f4f0e9`, cement `#ebe6dc`, mortar `#d5cec2`, ink 2 `#565047`.

## Screenshots of client work

`assets/shots/` holds one webp per screenshot (desktop 1600x1000, phone
600x1298), each used exactly once across the site. When a client site changes,
retake that shot rather than reusing another one.

## Deploying

Git deployments are enabled in `vercel.json`. The Vercel project
`mjl-collective` is linked to this repository and its production branch is
`main`: pushes to `main` deploy to mjlcollective.com, and pushes to any other
branch create preview deployments.

## Pages

- `/` home, `/work`, `/partners`, `/services`, `/about`, `/contact`, `/privacy`, `/terms`, and `404.html`.
- `/clients` is rewritten to the client portal app (`vercel.json`). Don't remove that rewrite.
- The client logo carousel and the Partners grid read from `CLIENTS` in `tools/build.py`, newest first.

## Brand

`brand/` holds the logo: SVG for the lockup and the monogram, in ink and in
white, plus PNG exports on white and on ink. `brand/README.md` states the
palette, the typeface, the minimum sizes and the clear space. Every site asset
in `assets/` (the header mark, the favicon, the touch icon, the social card and
the email mark) is generated from the same geometry, so regenerate them
together rather than editing one by hand.

`logo-directions.html` is the comparison page the mark was chosen from. It is
listed in `.vercelignore` and is not deployed.

## Contact form

`api/contact.js` is a Vercel serverless function ported from the previous
Next.js site. It validates the submission, drops honeypot hits, and sends
two emails through Resend: a notification to Mitchell (reply-to set to the
visitor) and a branded confirmation to the visitor. It needs the
`RESEND_API_KEY` environment variable in the Vercel project; without it the
function returns a 500 and the form shows the "email me directly" fallback.
